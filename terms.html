What Glassfolio is

README Glassfolio is a free website and command-line tool that builds a GitHub profile README, with images, from public GitHub data. It runs in your browser. Using it does not require an account. To confirm: the name of the person or organisation that operates this website.

Your content and your repository

  • The README and images are built from your own GitHub data and the text you type. You are responsible for what you publish, and for following GitHub's terms when you publish it.
  • Publish and daily updates make changes to your own profile repository using a token you provide. Check what will be committed before you publish. You can remove the files or the workflow at any time.
  • Only use a token that you are allowed to use, with the least access needed. The studio explains which permissions each action needs.

GitHub

Glassfolio relies on GitHub's public API, which has its own rate limits and terms. When GitHub is unavailable or limits requests, parts of Glassfolio will not work. Glassfolio is not affiliated with, sponsored by or endorsed by GitHub. GitHub is a trademark of GitHub, Inc.
