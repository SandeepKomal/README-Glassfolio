      Questions

      How will it look on a phone?

      Use the Phone switch above the preview to see it at a phone's width. Paired cards (stats and streak, projects, link buttons) stack and stay readable. The wide cards (heatmap, timeline, languages) shrink to fit, so their small text is harder to read on a small screen.

      Is my token safe?

      It's used only to talk to api.github.com from your browser tab and is never stored or sent anywhere else. That's enforced by the browser, not just promised: the page ships a strict security policy that only allows network requests to api.github.com and blocks injected scripts. Create a fine-grained token limited to your profile repo with Contents: Read and write, and delete it after publishing if you like.

      Why are there image files next to the README?

      GitHub won't display images embedded inside a README, but it does show images stored in the repo. So the README and its SVG cards travel together, and Publish handles that for you.

      How do the numbers stay up to date?

      Publishing saves a snapshot, so on its own the numbers go stale. Tick Daily updates and publishing also adds a small GitHub Action to your profile repo that rebuilds everything once a day and commits only when something changed. It uses no third-party actions: a copy of the generator goes into your repo so you can read it. You can also just open the tool and publish again whenever you like.

      What does my browser remember?

      Only your option choices (theme, job title, skills and so on), saved locally so they're there next time. Your tokens are never saved, and nothing is sent anywhere. "Reset all options" clears it.

      Can my profile be light in the morning and dark at night?

      Yes, for each visitor. Tick Day and night and every image gets a light twin. GitHub shows the dark set to visitors whose device or GitHub is in dark mode, and the light set to everyone else. Many phones and computers switch to dark at sunset by themselves (and back at sunrise), and an open page swaps live when they do. A README can't read the clock itself, because GitHub removes scripts, so it follows each visitor's own setting rather than a time you choose. A visitor who keeps their device in one mode always sees that one. It costs about twice as many files.

      Can I use my own colours, or choose which repos are shown?

      Yes. Pick Custom in the theme list to choose two accent colours (they're adjusted automatically so text stays readable). Under Order & projects you can reorder the sections and tick up to six repos to feature, in the order you want them.

      How do I get a PNG or a picture to share?

      Open the Files tab. Every image has SVG and PNG buttons, and there's a ready-made 1280×640 share image for LinkedIn, X or a repository social preview. You can also download every image as a PNG zip.

      Does it need a GitHub Action or a server?

      The tool itself is a static page: no server, nothing hosted for you. A GitHub Action is needed only if you want the stats to refresh by themselves, and that's optional. If you turn it on, it lives in your own repo, uses no third-party actions, and you can delete it any time.

      Will it show private contributions?

      With a token it uses your contribution calendar, which follows your GitHub setting for showing private contributions. Without a token it uses public activity only.

      The README is built only from public data: your profile, your repos, their languages and topics. Publish commits everything straight to your username/username repo. Or download the zip and upload all of it yourself (README.md, banner.svg and the cards folder): a missing image shows as a broken picture. GitHub allows 60 anonymous API requests an hour per network, and each profile uses about 8 without a token.
